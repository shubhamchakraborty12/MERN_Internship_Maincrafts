# Task Manager App

This project contains:
- Frontend: React + Vite
- Backend: Express + MongoDB

## Setup
1. In the backend folder, copy `.env.example` to `.env` and add your MongoDB Atlas connection string.
2. Install dependencies:
   - `cd backend && npm install`
   - `cd frontend && npm install`
3. Start the apps:
   - `cd backend && npm run dev`
   - `cd frontend && npm run dev`

The frontend uses the backend API at `http://localhost:5000` by default.
